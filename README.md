### Implementasi Program

- **Static Program**

[Static Programs](./Knights%20Tour%20Static/) hanya perlu dijalankan langsung, tiap program akan menjalankan ketiga level dari knight's tour.

- **Interactive Program**

[Interactive Programs](./Knights%20Tour%20Interactive/) dapat mengustomisasi level dari knight's tour. 
Yand dapat dikustomisasi
```
- Luas papan 
- Posisi awal kuda
- Jenis obstacle(rook / king)
- Posisi obstacle
```
